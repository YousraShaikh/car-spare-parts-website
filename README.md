# Car Spare Parts Website

A full-stack MERN web application developed during my internship for managing and purchasing car spare parts online.

## 🚀 Technologies Used

- MongoDB
- Express.js
- React.js
- Node.js
- HTML
- CSS
- JavaScript
- Bootstrap

## ✨ Features

- User-friendly responsive interface
- Car spare parts listing and management
- Product search and browsing
- User authentication and authorization
- Database integration using MongoDB
- Add to cart functionality
- Admin product management
- Backend API integration

## 📂 Project Structure

- Frontend - React.js
- Backend - Node.js & Express.js
- Database - MongoDB

## 🛠 Installation

1. Clone the repository

```bash
git clone https://github.com/YousraShaikh/car-spare-parts-website.git
```

2. Install dependencies

```bash
npm install
```

3. Start the backend server

```bash
npm start
```

4. Start the frontend

```bash
npm run dev
```
